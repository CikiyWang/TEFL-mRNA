# Supplementary Figure 6. ΔpTE of dbSNP common variants and gnomAD 5’UTR variants

## Supplementary Fig. 6A

Legend: Distribution of predicted TE changes (ΔpTE) among dbSNP common variants by annotation class. The y-axis indicates the percentage of variants in each class with ΔpTE above the thresholds.

Analysis: Distribution of predicted translational-efficiency changes (dPTE = pTE_ALT - pTE_REF)
among dbSNP common variants (common allele frequency 0.1-0.9, RefSeq NM transcripts), computed
separately for 5'UTR, synonymous, missense and 3'UTR variants. For each class the script reports
the fraction of transcript-variant pairs whose dPTE lies beyond a series of cutoffs; the tails
are cumulative rather than disjoint bins.

Input:
`input/pred_dbSNP-common_CAF_0.1_0.9.refseq_vep.NM_known.5_prime_UTR_variant.delta_selcols.tsv`
`input/pred_dbSNP-common_CAF_0.1_0.9.refseq_vep.NM_known.synonymous_variant.delta_selcols.tsv`
`input/pred_dbSNP-common_CAF_0.1_0.9.refseq_vep.NM_known.missense_variant.delta_selcols.tsv`
`input/pred_dbSNP-common_CAF_0.1_0.9.refseq_vep.NM_known.3_prime_UTR_variant.delta_selcols.tsv`

Analysis script: `analysis/FigS6A_analysis.R`

Plot script: `plot/FigS6A_plot.R`

Output: `output/FigS6A.pdf`, `output/FigS6A.png`, `output/FigS6A_source_data.tsv`

Run (from the `FigS6/` directory):

```
Rscript analysis/FigS6A_analysis.R
Rscript plot/FigS6A_plot.R
```

Dependencies: R (>= 4.0) with `data.table`, `ggplot2`, `scales` and `systemfonts`. Arial is used
when available and falls back to the default sans-serif otherwise. The PDF is written with
`cairo_pdf` when a working cairo library is available, otherwise with the macOS quartz PDF device
(both embed Arial), and otherwise with `pdf()` in Helvetica.

Notes: `output/FigS6A_source_data.tsv` holds the plotted values (class, cutoff, n_pairs,
n_beyond, percent) and is regenerated by the analysis script. Only the
`transcript_refid_var` and `delta_score_high` columns of the input tables are used; duplicated
transcript-variant keys carry identical dPTE values and are collapsed. The panel is drawn with
independent y scales per class and categories containing no variants are omitted.

## Supplementary Fig. 6B

Legend: Predicted ΔpTE for SNVs located within ±1000nt of the start or stop codon. Each point indicates an individual SNV; colors indicate the alternative allele. The x-axis shows the relative distance to the start codon.

Analysis: dPTE (pTE_ALT - pTE_REF) of gnomAD v4.0 exome SNVs on RefSeq NM transcripts within 1 kb
of the start codon (5'UTR and CDS) and of the stop codon (CDS and 3'UTR), plotted against distance
and coloured by ALT base. CDS SNVs are synonymous. Distances (nt) are: 5'UTR, from the base
immediately 5' of the AUG (1); CDS, from the A of the AUG (1) and to the last base of the stop
codon (0); 3'UTR, from the base immediately 3' of the stop codon (1). The panel shows dPTE between
-0.6 and 0.6 (one 5'UTR SNV lies outside this range).

Input: `input/gnomad_v4_SNVs_delta_pTE.start_stop_1kb.tsv.gz` (33,413,533 SNV-transcript pairs:
`region`, `transcript_refid_var`, `alt`, `distance_nt`, `delta_score_high`)

Analysis script: `analysis/FigS6B_analysis.R`

Plot script: `plot/FigS6B_plot.R`

Output: `output/FigS6B.pdf`, `output/FigS6B_summary.tsv`

Run (from the `FigS6/` directory):

```
Rscript analysis/FigS6B_analysis.R
Rscript plot/FigS6B_plot.R
```

Dependencies: R (>= 4.1) with `data.table`, `R.utils` (to read the .gz input), `ggplot2`, `ggpubr`,
`ggsci`, `patchwork` (>= 1.2), `ragg` and `png`.

Notes: the points are drawn into a 300-dpi raster per panel so the PDF stays small; axes and text
are vector. `output/FigS6B_summary.tsv` gives the number of SNVs per region and ALT base. The plot
script reads the input table directly; it is the plotted data. `analysis/FigS6BC_input_subset.R`
shows how the Supplementary Fig. 6B and S6C inputs were extracted from the genome-wide gnomAD tables. You do not
need it to reproduce the figure.

## Supplementary Fig. 6C

Legend: Fractions of transcripts with 4 alternative allele types (A/G/C/U) among 5’UTR SNVs exceeding different ΔpTE cutoffs. The colors show different types of alternative alleles.

Analysis: ALT-base composition of gnomAD v4.0 5'UTR SNVs that decrease (dPTE <= -0.1 to -0.5) or
increase (dPTE >= 0.1 to 0.5) predicted TE. Each bar gives the fraction of each ALT base among the
SNVs passing that cutoff; cutoffs are cumulative.

Input: `input/gnomad_v4_5UTR_SNVs_delta_pTE.abs_ge_0.1.tsv` (147,532 of 6,239,195 5'UTR
SNV-transcript pairs, those with |dPTE| >= 0.1, the smallest cutoff)

Analysis script: `analysis/FigS6C_analysis.R`

Plot script: `plot/FigS6C_plot.R`

Output: `output/FigS6C.pdf`, `output/FigS6C_source_data.tsv` (counts and fractions per class,
cutoff and ALT base)

Run (from the `FigS6/` directory):

```
Rscript analysis/FigS6C_analysis.R
Rscript plot/FigS6C_plot.R
```

Dependencies: R with `data.table`, `ggplot2` and `ggsci`.
