# Fig. S7D — source data and code

Change in base-pairing at the variant base for the five validated 5'UTR variants
that gain no upstream AUG. Previously panel **c** of the four-panel mechanism
supplement; renumbered here as **Fig. S7D**.

## Running

Run from the package root (`FigS7D/`); both scripts resolve paths relative to it:

```bash
python scripts/analysis_FigS7D.py     # source_data/variants_5utr_sequences.json
                                      #   -> source_data/FigS7D_source_data.csv
python scripts/plot_FigS7D.py         # source_data/FigS7D_source_data.csv
                                      #   -> figures/FigS7D.{pdf,png}
```

The plotting step reads only the source-data CSV, so the panel can be redrawn
without ViennaRNA installed.

Requires: Python >= 3.10, viennarna (analysis only), numpy, pandas, matplotlib.
Verified on: Python 3.12.14, ViennaRNA 2.7.2, NumPy 2.5.2, pandas 3.0.5,
Matplotlib 3.11.1 (macOS, Arial present). Arial is needed for exact font
reproduction; the style module falls back to Helvetica or DejaVu Sans otherwise.

## Method

Minimum free energy structures, partition functions and base-pair probability
matrices are computed with ViennaRNA at 37 °C using the default Turner 2004
nearest-neighbour parameters. The probability that nucleotide *i* is unpaired is
1 − Σ*j* p*ij*, summing the base-pair probability matrix over all partners *j*.

Folding is performed on the **isolated 5'UTR**. In the dual-luciferase reporter
the native CDS is replaced by the Nanoluc open reading frame, so the 5'UTR alone
is the sequence actually present upstream of the assayed ORF; folding the 5'UTR
together with its native CDS would not correspond to the assayed molecule.

*HLA-G* is excluded from this panel. Its mechanism is upstream-ORF creation
(Fig. S7A), and the large accessibility change at its variant base is incidental
to that mechanism rather than the cause of the effect. The panel tests secondary
structure as a mechanism for the five variants in which no upstream AUG is gained.
*HLA-G*'s values are retained in the per-variant supplementary table.

## Interpretation of the y axis

Higher values indicate a base that is single-stranded — and therefore accessible
to the scanning 43S complex — in a larger fraction of the Boltzmann ensemble.
1.0 means unpaired in essentially every structure; 0.0 means sequestered in a
stem in essentially every structure. The axis measures accessibility, not
translation: it identifies *PIK3C3* and *H3C4* as structure-mediated and rules
structure out for the three activating variants.

## Provenance

`FigS7D_source_data.csv` regenerates values identical to those in the reviewed
per-variant supplementary table (`TableS_variant_mechanisms.csv`) for all five
variants, to 3 decimal places.
